# End-to-End Data Pipeline: Web Scraping → Pandas → MySQL

Scrape data from live websites, clean it with Pandas, store it in MySQL,
and query it back into Pandas with SQL JOINs — the daily workflow of a
data analyst, in one small project.

Built by [Muhammad Suleman](https://github.com/Sallo70) — BS Computer
Science graduate, aspiring Data Analyst, learning AI/ML step by step.

## What it does

```
Website (HTML)  →  Requests + BeautifulSoup  →  Pandas DataFrame
                                                     ↓
MySQL (onlinestoredb)  ←  SQL JOINs + read_sql  ←  Clean data
```

1. **Scrape** — `scrape_quotes.py` loops pages 1–10 of
   [quotes.toscrape.com](https://quotes.toscrape.com) and extracts
   quote text, author and tags (`div.quote`, `span.text`,
   `small.author`, `.tags .tag`). `scrape_countries.py` scrapes
   [scrapethissite.com/pages/simple/](https://www.scrapethissite.com/pages/simple/)
   and extracts country name (`h3`) and population
   (`span.country-population`).
2. **Clean** — the scraped HTML is structured into Pandas DataFrames
   (in the original notebooks: `web_scraped/data_col.ipynb` and
   `web_scraped/ass_data.ipynb`; the scripts here are cleaned-up,
   runnable versions of that work).
3. **Store** — a MySQL database, `onlinestoredb`, with 5 tables:
   `customers` (5), `orders` (6), `order_items` (7), `payments` (6),
   `products` (5).
4. **Query** — SQL JOINs across `customers`–`orders`–`payments`, and
   `pandas.read_sql()` to read the results back into Pandas. A
   previous-order comparison (current vs. previous order amount per
   customer) is in `data/onlinestoredb.csv` and in `sql/queries.sql`
   using `LAG()`.

Python 3.10+.

## MySQL setup

```bash
# Option A — clean schema (column spelled `address`)
mysql -u root -p < sql/schema.sql

# Option B — the original dump, unchanged
mysql -u root -p < sql/onlinestoredb.sql
```

Then run the example queries:

```bash
mysql -u root -p onlinestoredb < sql/queries.sql
```

> **Note:** the original dump spells the customers column `adress`.
> The clean `sql/schema.sql` uses `address`. If you load the original
> dump, use `adress` in your queries.

Reading the JOIN back into Pandas:

```python
import pandas as pd
import mysql.connector

conn = mysql.connector.connect(
    host="localhost", user="root", password="YOUR_PASSWORD",
    database="onlinestoredb"
)
df = pd.read_sql(
    "SELECT c.name, o.order_id, o.order_date, p.amount "
    "FROM customers c "
    "JOIN orders o ON c.customer_id = o.customer_id "
    "JOIN payments p ON o.order_id = p.order_id",
    conn
)
print(df.head())
```
